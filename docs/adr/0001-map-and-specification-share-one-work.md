# A map and the specification it produces are one work

Wayfinding maps and specification bundles arrived as separate ideas, but in practice a map exists to reach a destination that is usually the specification itself — the first real map produced a bundle and could only reference it as loose text across two identifiers. So a work holds both: `map.md` and `tickets/` sit beside `spec.md`, `issues.md`, and `learnings.md`, addressed by one identifier.

## Consequences

A work no longer requires `spec.md`. Charting a map creates the work months before a specification exists, so existence is the work's directory, not any one artifact. This gives up the earlier invariant that a work only comes into being once `to-prd` has produced a complete specification.
